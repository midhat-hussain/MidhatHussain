### <img width="15" height="15" alt="waze" src="https://github.com/user-attachments/assets/92b571fe-562d-44b0-9cef-d2939c4b9539" /> Waze - Optimizing-Drivers-Retention

**Objective**: Develop a machine learning model to predict monthly user churn for Waze.

**Methodology**: Performed extensive Exploratory Data Analysis (EDA) to identify key features and behavioral patterns correlated with user attrition. 
Built and validated a predictive model using Python (Scikit-learn) that identifies users at high risk of churning, to establish targeted retention strategies.

**Outcome**: 
The model predicted three times as many false negatives than it did false positives, and it correctly identified only 16.6% of the users who actually churned.

The default decision threshold for most implementations of classification algorithms—including scikit-learn's—is 0.5. With imbalanced datasets where the response class is a minority, this threshold might not be ideal. A precision-recall curve can help to visualize the trade-off between our model's precision and recall.

To break past this 50% wall, the organization needs to collect behavioral sentiment data (e.g., user reports filed, app crashes experienced, or navigation layout changes) rather than just raw mileage metrics.

Tools & Libraries: Python | Pandas | NumPy | Seaborn | Plotly | Scikit-Learn | XGBoost

### 🌐 Unicorn-Data-Insights

**Objective**: Analyze Unicorn Companies data to provide insights into how and when companies
achieve the prestigious $1B valuation milestone.

**Methodology**: Conducted Data Analytics & Visualization to track valuation growth rates, funding
rounds, and time-to-unicorn metrics across various industries.

**Outcome**: 
Technology-driven sectors (Software, Fintech, AI) dominate Canada’s unicorn ecosystem, both in valuation and investor attention.

Companies founded in certain periods reach unicorn status faster than the historical average, highlighting favorable market timing and ecosystem maturity.

Canada’s unicorn presence, while smaller than global leaders, demonstrates strong specialization rather than broad diversification.

Overall, the Canadian unicorn ecosystem reflects a focused, innovation-led growth model supported by concentrated investor confidence.


Tools & Libraries: Python | Pandas | Seaborn | Plotly
